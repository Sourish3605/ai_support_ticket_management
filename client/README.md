# Support AI Ticket Management Frontend

A modern React + Vite support platform with authentication, ticket workflows, analytics, AI assistant chat, and settings.

## Features
- Responsive login and registration experience
- Protected dashboard layout with sidebar and top navigation
- KPI cards, charts, recent tickets, and ticket details
- Create ticket, my tickets, all tickets, AI assistant, reports, and settings pages
- Reusable components and mock service data for rapid UI development

## Tech Stack
- React
- Vite
- React Router
- Tailwind CSS
- Axios
- React Icons
- Recharts

## Setup
1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Open the local Vite URL shown in the terminal.
